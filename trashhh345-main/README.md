
  # v3

  This is a code bundle for v3. The original project is available at https://www.figma.com/design/Lo51u7lrXC58mswix543po/v3.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

## Supabase setup

1. Copy `.env.example` to `.env`.
2. Fill your Supabase values:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`

## Backend API

Run `npm run backend` to start the backend on `http://localhost:4000`.

Available endpoints:
- `GET /health`
- `GET /api/profiles`
- `POST /api/profiles`
